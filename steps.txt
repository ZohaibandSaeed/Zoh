STEP 2: CORE URL SHORTENER ENGINE & INSTANT REDIRECTION (/[slug]) [COMPLETED]
--------------------------------------------------------------------------------
Goal:
User-defined custom short URLs create karna, database uniqueness verify karna,
aur ultra-fast redirection engine implement karna.

Tasks & Architecture:
1. Custom Slug Validation & Sanitization:
   - Input cleaning: spaces to dashes, lowercase conversion, special character filtering.
   - Reserved slugs protection (e.g. 'list', 'login', 'api', 'dashboard', 'favicon.ico'
     allow nahi honge taake system break na ho).
   - Duplicate Check:
     Query: SELECT id FROM urls WHERE slug = $1;
     Agar exist kare -> Error: "Slug already exists, choose another name".

2. URL Creation Dashboard UI (`/dashboard`):
   - Professional form with Original URL input (URL format validation).
   - Custom Slug input with live preview: `zoh.netlify.app/{custom_slug}`.
   - Real-time feedback and submit button.
   - Success modal/card displaying generated link with instant "Copy Link" button.

3. Ultra-Fast Dynamic Redirection Engine (`app/[slug]/route.ts`):
   - Dynamic route extracting slug from URL parameters.
   - Database query:
     SELECT original_url FROM urls WHERE slug = $1;
   - If found:
     * Increment `clicks` counter asynchronously (background update).
     * Issue HTTP 307 Temporary / 302 Found Redirect to target URL.
   - If not found:
     * Display a clean, branded 404 "Short link not found" page with a button
       to explore the public directory (`/list`).

Output of Step 2: [VERIFIED & PASSING]
User custom slug daal kar short link bana sakta hai, duplicate check kaam karta hai,
